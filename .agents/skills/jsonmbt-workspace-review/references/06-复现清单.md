# 复现清单

> 命令直接抄（本清单全部命令建账时亲跑验证过）。除注明者外，cwd = 仓库根。

```bash
export PATH="$HOME/.moon/bin:$PATH"
cd <repo>
```

---

## 0 · 审阅开场（防假绿）

```bash
git log --oneline -8
git status --short -uall          # -uall 才看得见未跟踪目录里的文件
git diff --stat
git log -1 --stat <HEAD>

# 本仓无 oracle、无版本门（Vitro 的 shadow_verify 在此无对应物）——
# 防假绿改为：跨会话接过工作区先清 _build（04 表 #2）
rm -rf _build && MOON_CC=clang moon build --target native
```

## 1 · 内层门禁（moon 面）

```bash
moon check                        # warning 总数当回归信号；偶发文件锁 ⇒ 重试一次
moon test                         # 内层语义锚；计数真值以本次输出为准
moon test -p vitro/jsonmbt/src    # 单包口径（选择器须全限定名）
moon test -p cmd/jsonmbt --target native   # CLI 包是 native-only，不带 target 会撞 wasm 拒绝
moon fmt                          # 跑完看 git status/diff（--check 本机 exit 127 不可用）

MOON_CC=clang moon build --target native   # 纪律 9；MSVC 悬崖
```

## 2 · CLI 抽验（D-10 / D-8 进程契约）

```bash
CLI=_build/native/debug/build/cmd/jsonmbt/jsonmbt.exe

$CLI check probe/samples/server.json.mbt; echo rc=$?     # rc 契约（裸命令取 rc，禁接管道后 echo $?）
$CLI check probe/samples/README.md; echo rc=$?           # 非 .json.mbt 输入 ⇒ J0001 / rc 4

# 确定性：两次 build 逐字节 diff
$CLI build probe/samples/server.json.mbt -o tmp/r1.json
$CLI build probe/samples/server.json.mbt -o tmp/r2.json
diff tmp/r1.json tmp/r2.json && echo DETERMINISTIC

# stdin 形态
printf '...' | $CLI check -                                # `-` 必须是唯一输入
printf '...' | $CLI build -                                # stdin 产物走 stdout

# 原子写三态（D-8 ①③）：坏输入 build ⇒ 失败零产物；好输入重复 build ⇒ 覆盖成功且无 tmp 残留
```

## 3 · 样本锚三层连跑

```bash
                                  # 改降级器 / 校验器后三层全部重验（AGENTS 环境注意）
```

## 4 · 白盒探针 / 突变注入

```bash
# 临时探针：src/*_test.mbt 内 test 块 + fail(s) dump，用完即删
moon test -p vitro/jsonmbt/src 2>&1 | sed -n '/FAILED:/,$p' | sed '1s/.*FAILED: //'

# 突变循环：备份 → replace(old,new,1) → sleep ≥1.5s → moon test → 记录 failed → 还原复跑
# 独立探针工程：tmp/review_YYYYMMDD/<name>/{moon.mod, src/moon.pkg, ...}
```

## 5 · 收尾（每次必做）

```bash
git status --short -uall          # 零残留（除审阅前就存在的第三方改动）
# 探针文件逐个删；改写过的源码文件核字节；tmp/ 下的本轮留证按需保留并报告相对路径
```

## 6 · 平台 / 环境速查

| 事项 | 取法 |
|---|---|
| PATH | `export PATH="$HOME/.moon/bin:$PATH"`（本仓 bash 工具层 heredoc 吃反斜杠——陷阱 #19，跨 heredoc 写文件用 python 中转） |
| 判 rc | 裸命令 + `echo $?`；管道后 `$?` 是尾命令的（04 表 #3） |
| 取 moon 版本 | `moon version` |
| 判文件字节 / 行尾 | 一律看字节（`od -c` / `xxd`），别信编辑器渲染 |
| 判 git 忽略 | `git check-ignore -v <path>` |
| CLI exe 位置 | `_build/native/debug/build/cmd/jsonmbt/jsonmbt.exe` |

## 7 · 常用口径

| 概念 | 口径 |
|---|---|
| 判据来源 | RFC 8259 + moon 实测 + PLAN §8 D 系裁定（**无 oracle**） |
